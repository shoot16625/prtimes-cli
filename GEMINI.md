# prtimes-cli

This extension adds skills for PR TIMES, built on the bundled `prtimes-cli` (`dist/prtimes-cli.js` in this extension's directory, run with [Bun](https://bun.sh)). Load the matching skill before acting:

- `skills/draft/SKILL.md`: save, update and delete press release drafts written in Markdown
- `skills/releases/SKILL.md`: list and read your company's releases, and check dashboard numbers
